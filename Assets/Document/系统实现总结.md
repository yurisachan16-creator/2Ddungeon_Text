## 🔧 技术实现亮点

### 1. 接口设计
```csharp
public interface IState
{
    void OnEnter();
    void OnUpdate();
    void OnFixedUpdate();
    void OnExit();
}
```
- 清晰的生命周期管理
- 分离逻辑更新和物理更新
- 易于理解和实现

### 2. 状态缓存机制
```csharp
private Dictionary<System.Type, IState> stateCache = new Dictionary<System.Type, IState>();
```
- 避免频繁创建对象
- 提升性能
- 保持状态数据

### 3. 反射访问私有字段
```csharp
var field = typeof(CharacterBase).GetField("isAttacking", 
    System.Reflection.BindingFlags.NonPublic | System.Reflection.BindingFlags.Instance);
field?.SetValue(characterBase, true);
```
- 解决访问限制问题
- 保持封装性
- 灵活的实现方式

### 4. 组件自动获取
```csharp
protected virtual void Awake()
{
    rb = GetComponent<Rigidbody2D>();
    animator = GetComponent<Animator>();
    spriteRenderer = GetComponent<SpriteRenderer>();
}
```
- 减少手动配置
- 降低出错概率
- 提升开发效率

## 🎮 Unity设置要点

### 必需配置
1. **Tags**
   - Player
   - Enemy

2. **Layers**
   - Layer 6: Room（已存在）
   - Layer 7: Enemy（新增）
   - Layer 8: Player（可选）

3. **Input Manager**
   - Horizontal: A/D或左右箭头
   - Vertical: W/S或上下箭头
   - Mouse Button 0: 左键
   - Mouse Button 1: 右键

### 推荐组件设置
```
GameObject: Knight
├─ Tag: Player
├─ Layer: Default或Player
├─ Transform
├─ KnightController
│   ├─ Max Health: 100
│   ├─ Move Speed: 5
│   ├─ Attack Damage: 10
│   ├─ Attack Range: 1.5
│   └─ Attack Point: [分配子对象]
├─ Rigidbody2D
│   ├─ Body Type: Dynamic
│   ├─ Gravity Scale: 0
│   └─ Constraints: Freeze Rotation Z
├─ Animator
│   └─ Controller: [分配控制器]
├─ Sprite Renderer
│   └─ Sprite: [分配精灵]

    └─ Size: 根据精灵调整

## 🐛 常见问题快速解决

| 问题 | 可能原因 | 解决方案 |
|------|----------|----------|
| 角色不移动 | 未在FixedUpdate中移动 | 检查OnFixedUpdate实现 |
| 状态不切换 | 未设置初始状态 | Start()中调用ChangeState |
| 动画不播放 | 参数名不匹配 | 核对Animator参数名 |
| 攻击无效果 | Layer设置错误 | 检查Enemy Layer配置 |
| 编译错误 | 缺少using语句 | 添加using UnityEngine; |

### 命名规范
- **类名**: 大驼峰 + 后缀（`KnightIdleState`）
- **方法名**: 大驼峰（`PerformAttack`）
- **字段名**: 小驼峰（`moveSpeed`）

```

├─ {角色名}AttackState.cs
