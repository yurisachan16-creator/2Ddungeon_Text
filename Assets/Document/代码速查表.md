## 1. IState接口（必须实现4个方法）

```csharp
public interface IState
{
    void OnEnter();        // 进入状态
    void OnUpdate();       // 每帧更新
    void OnFixedUpdate();  // 物理更新
    void OnExit();         // 退出状态
}
```

**使用场景**：创建任何新状态都必须实现此接口

## 2. StateMachine类（状态管理器）

### 常用方法
```csharp
// 创建状态机
StateMachine stateMachine = new StateMachine();

// 切换状态（推荐用法）
stateMachine.ChangeState(new IdleState(this));

// 在MonoBehaviour的Update中
void Update()
{
    stateMachine?.Update();
}

// 在MonoBehaviour的FixedUpdate中
void FixedUpdate()
{
    stateMachine?.FixedUpdate();
}
```

**关键特性**：
- ✅ 自动缓存状态实例
- ✅ 防止切换到相同状态
- ✅ 自动调用OnExit/OnEnter

## 4. 状态类实现模板

### 最小实现
```csharp
public class YourState : IState
{
    private CharacterBase character;
    private Animator animator;
    
    public YourState(CharacterBase character)
    {
        this.character = character;
        this.animator = character.Animator;
    }
    
    public void OnEnter()
    {
        // 播放动画
        animator?.SetTrigger("YourAnimation");
    }
    
    public void OnUpdate()
    {
        // 检测死亡
        if (character.IsDead)
        {
            character.StateMachine.ChangeState(new DeathState(character));
            return;
        }
        
        // 状态逻辑...
        
        // 状态转换
        if (某个条件)
        {
            character.StateMachine.ChangeState(new NextState(character));
        }
    }
    
    public void OnFixedUpdate()
    {
        // 物理操作（移动等）
    }
    
    public void OnExit()
    {
        // 清理工作
    }
}
```

### 带计时器的状态
```csharp
public class TimedState : IState
{
    private CharacterBase character;
    private float duration = 1f;
    private float timer = 0f;
    
    public TimedState(CharacterBase character)
    {
        this.character = character;
    }
    
    public void OnEnter()
    {
        timer = 0f;
    }
    
    public void OnUpdate()
    {
        timer += Time.deltaTime;
        
        if (timer >= duration)
        {
            character.StateMachine.ChangeState(new NextState(character));
        }
    }
    
    public void OnFixedUpdate() { }
    public void OnExit() { }
}
```

## 6. 状态转换模式

### 标准转换检查顺序
```csharp
public void OnUpdate()
{
    // 1. 检测死亡（最高优先级）
    if (character.IsDead)
    {
        character.StateMachine.ChangeState(new DeathState(character));
        return;
    }
    
    // 2. 检测受伤
    if (character.IsHurt)
    {
        character.StateMachine.ChangeState(new HurtState(character));
        return;
    }
    
    // 3. 检测特殊状态（攻击等）
    if (Input.GetMouseButtonDown(0))
    {
        character.StateMachine.ChangeState(new AttackState(character));
        return;
    }
    
    // 4. 检测移动
    float horizontal = Input.GetAxisRaw("Horizontal");
    if (horizontal != 0)
    {
        character.StateMachine.ChangeState(new MoveState(character));
        return;
    }
    
    // 5. 默认保持当前状态或返回Idle
}
```

## 8. 动画参数配置

### Animator Controller必需参数

| 参数名 | 类型 | 用途 |
|--------|------|------|
| Speed | Float | 移动速度（0=静止，1=移动）|
| IsAttacking | Bool | 是否在攻击中 |
| Attack01 | Trigger | 触发攻击1动画 |
| Attack02 | Trigger | 触发攻击2动画 |
| Hurt | Trigger | 触发受伤动画 |
| Death | Trigger | 触发死亡动画 |

### 动画过渡设置建议
- **Idle → Move**: Condition: Speed > 0.1
- **Move → Idle**: Condition: Speed < 0.1
- **Any State → Attack**: Trigger: Attack01/Attack02
- **Any State → Hurt**: Trigger: Hurt
- **Any State → Death**: Trigger: Death

## 11. 常见问题解决

### Q: 状态无法切换
**检查**:
1. 是否在Start()中设置了初始状态？
2. 是否每帧都强制切换回原状态？
3. 是否忘记调用`stateMachine.Update()`？

### Q: 移动不生效
**检查**:
1. 是否在OnFixedUpdate()中进行移动？
2. Rigidbody2D的Body Type是否为Dynamic？
3. MoveSpeed是否设置为0？

### Q: 动画不播放
**检查**:
1. Animator Controller是否已分配？
2. 参数名称是否正确匹配？
3. 动画过渡条件是否设置正确？
4. Has Exit Time是否需要取消勾选？

### Q: 攻击无效
**检查**:
1. AttackPoint是否已分配？
2. Enemy Layer设置是否正确？
3. 敌人对象的Layer是否匹配？
4. Attack Range是否过小？

## 12. 性能优化建议

### 缓存组件引用
```csharp
// ❌ 不好：每帧查找
void Update()
{
    GameObject player = GameObject.FindGameObjectWithTag("Player");
}

// ✅ 好：缓存引用
private Transform player;
void OnEnter()
{
    if (player == null)
    {
        GameObject playerObj = GameObject.FindGameObjectWithTag("Player");
        player = playerObj?.transform;
    }
}
```

### 使用对象池
```csharp
// 投射物应该使用对象池而非频繁Instantiate/Destroy
```

### 减少每帧检测
```csharp
// ❌ 不好：每帧检测
void OnUpdate()
{
    CheckAllEnemies();
}

// ✅ 好：定时检测
private float checkTimer = 0f;
private float checkInterval = 0.5f;

void OnUpdate()
{
    checkTimer += Time.deltaTime;
    if (checkTimer >= checkInterval)
    {
        CheckAllEnemies();
        checkTimer = 0f;
    }
}
```
