# 角色状态机快速开始指南

## 快速使用 - Knight角色设置（5分钟）

### 1. 创建Knight角色
1. 在场景中创建空GameObject，命名为"Knight"，Tag设置为"Player"
2. 添加组件：
   ```
   - KnightController（脚本）
   - Rigidbody2D（2D刚体）
     └─ Gravity Scale: 0
     └─ Freeze Rotation: Z轴勾选
   - Animator（动画控制器）
   - Sprite Renderer（精灵渲染）
   - Box Collider 2D（碰撞体）
   ```

### 2. 创建攻击检测点
1. 在Knight下创建子对象：右键 → Create Empty → 命名为"AttackPoint"
2. 移动AttackPoint到角色前方（武器位置）
3. 在KnightController组件中：
   - 拖拽AttackPoint到"Attack Point"字段

### 3. 设置Layer
1. 菜单 → Edit → Project Settings → Tags and Layers
2. 添加新Layer：
   - Layer 7: "Enemy"
3. 在KnightController中：
   - Enemy Layer设置为"Enemy"

### 4. 配置动画（如果有Animator）
创建Animator Controller，添加参数：
- **Float**: Speed
- **Bool**: IsAttacking  
- **Trigger**: Attack01, Attack02, Hurt, Death

### 5. 测试
运行游戏：
- **WASD**: 移动
- **鼠标左键**: 攻击1
- **鼠标右键**: 攻击2

## 创建自己的角色（3步骤）

### 例子：创建Boss角色

#### 步骤1：创建状态类
创建文件：`Assets/Scripts/Character/Boss/BossIdleState.cs`

```csharp
using UnityEngine;

public class BossIdleState : IState
{
    private CharacterBase character;
    
    public BossIdleState(CharacterBase character)
    {
        this.character = character;
    }
    
    public void OnEnter()
    {
        // 进入空闲状态的逻辑
    }
    
    public void OnUpdate()
    {
        // 每帧更新逻辑
        // 检测玩家、切换状态等
    }
    
    public void OnFixedUpdate() { }
    public void OnExit() { }
}
```

#### 步骤2：创建控制器
创建文件：`Assets/Scripts/Character/Boss/BossController.cs`

```csharp
using UnityEngine;

public class BossController : CharacterBase
{
    protected override void Awake()
    {
        base.Awake();
        characterType = CharacterType.Boss;
    }
    
    protected override void Start()
    {
        // 设置初始状态
        stateMachine.ChangeState(new BossIdleState(this));
    }
}
```

#### 步骤3：添加到场景
1. 创建GameObject，添加`BossController`组件
2. 设置生命值、移动速度等参数
3. 完成！

## 常用代码片段

### 状态切换
```csharp
// 在任何状态的OnUpdate中
character.StateMachine.ChangeState(new NewState(character));
```

### 检测玩家距离
```csharp
GameObject player = GameObject.FindGameObjectWithTag("Player");
float distance = Vector2.Distance(character.transform.position, player.transform.position);
if (distance < 5f)
{
    // 玩家在5格范围内
}
```

### 面向目标
```csharp
Vector2 direction = (target.position - character.transform.position).normalized;
if (direction.x != 0)
{
    character.transform.localScale = new Vector3(Mathf.Sign(direction.x), 1, 1);
}
```

### 攻击检测
```csharp
Collider2D[] hits = Physics2D.OverlapCircleAll(attackPoint.position, attackRange, enemyLayer);
foreach (Collider2D hit in hits)
{
    CharacterBase enemy = hit.GetComponent<CharacterBase>();
    enemy?.TakeDamage(attackDamage);
}
```

### 造成伤害
```csharp
// 让其他角色受伤
otherCharacter.TakeDamage(10f);
```

## 动画控制参数对照表

| 参数名 | 类型 | 用途 | 设置方式 |
|--------|------|------|----------|
| Speed | Float | 控制移动动画 | `animator.SetFloat("Speed", value)` |
| IsAttacking | Bool | 攻击状态标志 | `animator.SetBool("IsAttacking", true)` |
| Attack01 | Trigger | 触发攻击1 | `animator.SetTrigger("Attack01")` |
| Attack02 | Trigger | 触发攻击2 | `animator.SetTrigger("Attack02")` |
| Hurt | Trigger | 触发受伤 | `animator.SetTrigger("Hurt")` |
| Death | Trigger | 触发死亡 | `animator.SetTrigger("Death")` |

## 调试检查清单

遇到问题时，按顺序检查：

- [ ] 是否调用了`stateMachine.ChangeState()`设置初始状态？
- [ ] Rigidbody2D的Gravity Scale是否设为0？
- [ ] 角色的Tag和Layer是否正确设置？
- [ ] Animator Controller的参数是否已创建？
- [ ] AttackPoint是否已分配并位置正确？
- [ ] 是否有错误日志输出？

## 快速参考

### 继承层次
```
MonoBehaviour
  └─ CharacterBase（角色基类）
       ├─ KnightController（近战玩家）
       ├─ RangedEnemyController（远程敌人）
       └─ YourController（你的角色）
```

### 状态生命周期
```
OnEnter() → OnUpdate()（每帧） → OnFixedUpdate()（物理帧） → OnExit()
```
